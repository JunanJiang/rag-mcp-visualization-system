# 压力系数Cp计算与分析

压力系数（Cp）是衡量物面压力分布的核心无量纲参数，广泛用于气动性能评估。

## 定义与计算

$$C_p = \frac{p - p_\infty}{\frac{1}{2} \rho_\infty V_\infty^2}$$

从Plot3D无量纲化变量计算：

```
p = (γ-1)[Q5 - 0.5·Q1·(u² + v² + w²)]
p∞ = 1/(γ·Ma∞²)  （标准无量纲化下）
q∞ = 0.5·γ·Ma∞²·p∞
Cp = (p - p∞) / q∞
```

## 工程解读

| Cp范围 | 含义 | 工程意义 |
|--------|------|---------|
| Cp = 1.0 | 驻点压力 | 前缘驻点位置 |
| Cp > 0 | 正压区 | 压力高于来流，减速增压 |
| Cp < 0 | 负压区（吸力区） | 压力低于来流，加速降压 |
| Cp < -1.0 | 强吸力区 | 通常对应加速区或分离涡核心 |
| Cp_min 位置 | 最低压力点 | 此后压力回升，易发生分离 |

## 典型应用

- **翼型分析**：上表面Cp分布反映升力生成，前缘吸力峰越高升力越大
- **逆压梯度**：Cp沿流向增大的区域为逆压梯度区，分离风险高
- **激波位置**：Cp曲线的不连续跳变通常对应激波位置
- **设计验证**：将CFD的Cp分布与风洞实验数据对比，偏差小于5%认为吻合良好
