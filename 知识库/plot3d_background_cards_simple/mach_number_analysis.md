# 马赫数分析与工程意义

马赫数（Mach Number）定义为流体速度与当地声速之比，是可压缩流动分析中最重要的无量纲参数。

## 流动分类

| 马赫数范围 | 流动类型 | 典型特征 |
|-----------|---------|---------|
| Ma < 0.3 | 不可压缩流 | 密度变化可忽略，简化为常密度求解 |
| 0.3 ≤ Ma < 0.8 | 亚声速可压缩流 | 需考虑密度变化，无激波 |
| 0.8 ≤ Ma < 1.2 | 跨声速流 | 局部超声速区域，可能出现激波 |
| 1.2 ≤ Ma < 5.0 | 超声速流 | 存在斜激波和膨胀波系统 |
| Ma ≥ 5.0 | 高超声速流 | 强激波、高温气体效应显著 |

## 工程解读指南

- **马赫数分布均匀性**：Ma变化范围小于±5%时，认为流场较为均匀
- **局部马赫数峰值**：超过来流Ma的1.5倍时，需关注气动加热和结构载荷
- **马赫数等值线密集区**：通常对应激波位置或强压缩/膨胀区域
- **壁面马赫数为零**：满足无滑移边界条件，属于正常物理现象

## 从Plot3D数据计算马赫数

```
u = Q2/Q1, v = Q3/Q1, w = Q4/Q1
p = (γ-1)[Q5 - 0.5·Q1·(u² + v² + w²)]
a = √(γ·p/Q1)  （当地声速）
Ma = √(u² + v² + w²) / a
```
